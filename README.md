# TinDog 🐕

A responsive landing page for TinDog, a fictional platform that helps dogs find their perfect match.

## About the Project

Built as part of Angela Yu's Web Development Bootcamp to practise HTML, CSS and Bootstrap 5.

## Features

- Responsive navigation bar.
- Gradient background design.
- Hero section with app download buttons.
- Features section with custom SVG icons.
- Testimonial section.
- Three pricing plans.
- Responsive footer.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.8
- SVG icons

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Ensure the CSS and image folders remain in their correct locations.
